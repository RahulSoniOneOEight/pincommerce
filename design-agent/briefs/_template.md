# PinCommerce Screen Design Brief

Screen: replace-screen-id
Workflow: brief-to-screen
Viewport: 390x844
Theme: theme-b-blue

## Context
- Product & audience: PinCommerce mobile commerce experience.
- Platform: mobile app/web viewport.
- Brand mood: premium, modern, commercially clear, system-led.

## Objective
- State one screen and the primary user goal it serves.

## Inputs
- Sections/content from top to bottom.
- Existing semantic tokens and reusable components to inspect before creating anything new.
- Visual references: describe what to borrow and what to ignore.

## Constraints
- Use existing components where suitable; instantiate rather than redraw.
- Bind colors, spacing, radius and typography to semantic tokens.
- Use a 4px spacing rhythm.
- Keep output Penpot-native and editable.
- Do not introduce a parallel ad-hoc color system.

## Acceptance Criteria
- One clear visual hierarchy and merchandising/action priority.
- WCAG AA contrast targets: 4.5:1 normal text, 3:1 large text and UI where applicable.
- Consistent 4px spacing rhythm.
- Build section-by-section with direction approval before meaningful canvas changes.
- Run design-quality and accessibility review before visual approval.
